# Curation file contracts

`--ledger-curation-file-contracts <native-audit> <frozen-app> <fresh-output> <date> [--negative-control]` executes the frozen/current curation screen's protein and composition CSV paths. It checks exact chooser filters/default filenames, Cancel preserving an existing destination, accepted native files, byte equality and invariant formatting across `en-US` and `pt-BR`.

Frozen success/error messages are intercepted at the compiled platform calls. The instruction copier preserves locals, branches and exception regions. Each boundary has an exact expected call count, with one call still the default. A deliberately incorrect message-call count must be rejected. No real chooser or message box appears; every host is positioned offscreen before showing and must remain inactive.

The next small group executes both native bundled engines on the same owned target-only FASTA. Each program writes its FCF, retained JSON agrees after only the authorized retired-XIC omission, and both actual identity-search APIs reject the missing decoy measurement with the same message. The input FASTA must remain unchanged. Engine payloads are copied to the fresh output and selected through the process-local override, which is restored afterward.

The producer validates its five-row `FL-curation-file-contracts.json` with the existing native receipt validator before emitting it. This packet leaves ledger activation to the desk. Its `target-audit.json` lists the remaining 56 OPEN format/storage IDs with one-line reasons. Source audit and current ledger snapshots, executed checker sources, binaries, native files and traces are retained.

The initial old one-call copier failed the actual frozen handler, before any popup could appear. The exact-count implementation rejects wrong counts. Deliberately corrupting the current composition files gives two intended byte-check failures. The measured green runs pass 15 checks with no failures/skips, and all 17 product/capture/engine files repeat byte for byte. No product code changes or quick/golden/full suite are part of this tests-only packet.
