# Native file contracts

M52 assigns the remaining OPEN `format/export` and `export/storage fact` observations across screens. This packet proves actual file behavior by screen and format. It leaves explanatory copy and untested input paths OPEN.

Run from the worktree after a Release build:

```bash
export DOTNET_PROCESSOR_COUNT=4
FamilyQuant.Tests/bin/Release/net10.0-windows7.0/FamilyQuant.Tests.exe --ledger-file-contracts <native-audit> D:/FamilyQuant-data/reference-1.5.0.6/app <fresh-output> "$(date '+%F %T %z')"
```

The producer validates the native audit inventory and the frozen assembly commit. It uses synthetic inputs under `en-US` and `pt-BR`, writing actual FCF, protein report CSV, partition CSV and homology CSV files with the frozen and current program code.

The partition Save action captures its native chooser configuration, preserves an existing destination on cancellation, and writes the accepted file. The moved Results homology export follows the same cancel and accept scenarios. Frozen compiled methods retain their instructions, locals and exception regions; only the named native dialog boundary is replaced. Every shown proof window is positioned offscreen before showing and must remain inactive.

The five chooser facts are the partition CSV filename, filter and default extension, and the homology CSV filename and filter. Their accepted output files must agree byte for byte. The homology chooser's added explicit `.csv` default extension is retained in `screen-dialogs.json`; this packet does not claim that property is identical to the frozen chooser.

Three further stored-value facts use those actual FCF/CSV files: quoted multiline annotations persist, annotations supply family names while changing no nonzero family-quantitation value in the fixture, and an accession marker survives the file writes and frozen reopen. Native frozen/current naming and quantitation APIs execute before and after the annotation edit. `annotation-claims.json` retains every returned value; the CSV parser reads the annotation field back from the exported file. These checks introduce no new scientific rule.

FCF writes have the authorized X7 format difference: current writes omit the retired `XIC` property. The producer removes only that property from the parsed frozen document, compares all retained data, and requires the frozen reader to reopen the current annotation-bearing file. It does not claim raw FCF byte parity.

`FL-file-contracts.json` contains the native register. `target-audit.json` accounts for every supplied OPEN target-kind row: proved, excluded because Shell owns the pending CSV batch, or explicitly unproved with a wording/reason entry. `wording-file-gaps.tsv` supplies five decision entries, including a replacement for a previously empty current status and an explicitly compiled refusal fragment whose branch was not executed. The reader accepts quoted TSV cells containing real line breaks and normalizes the retained `cohort-wording.tsv` snapshot. That filename deliberately stays outside the append tool's `wording-*.tsv` input pattern. None of these list entries supplies a proof or changes a ledger state. The shared list remains Paulo's decision input.

Add `--negative-control` to corrupt current partition outputs and one numeric leaf in the captured annotation result. It requires a red native run. The resulting register must be rejected by `--feature-ledger-evidence-import` before any committed register is changed. Repeat the green producer into a second fresh folder and compare the product files and native screen captures byte for byte. Numerical invariance compares every numeric JSON leaf and its complete path; annotated and fallback family names are checked separately because the names should change.

This is a format and routing fixture. It does not recompute a scientific project, run RAW extraction, execute USEARCH, verify input parsers, or establish equivalence of the unproved help/status claims. No product code is changed. Per the desk's M41 rule, validation is a Release build, these focused runs and the native ledger check; quick, golden and the full suite are not run for this tests-only packet.

The M52 packet is retained at `D:/FamilyQuant-data/out-floater/formats/publish-1` and `publish-2`. Both runs passed 23 checks with no failures or skips. The six deliberate negative-control failures were rejected by the native importer before a register write. The current append selected exactly five candidates and appended exactly those five decision entries.
