# De novo workflow Help evidence

The Help menu page **De novo in FamilyQuant** is generated by
`FamilyQuant.Core/DeNovoWorkflowHelp.cs`. The same text is included in Quantify
Help and the general and optional review Help pages. The following code anchors
support every claim in its seven numbered paragraphs.

| Step | Claim | Code evidence |
|---|---|---|
| 1 | Quantify reads matched RAW and trusted SEPro inputs; the optional .plp route is separate | `FullXicInputStage.Prepare`, `FullXicRunMatch`, `ComputeXicViewModel.ComputeAsync`, `QuantitationProfile` |
| 2 | Source selection and confidence scales stay separate; displayed defaults come from code | `FullXicSourceStage.Read`, `DeNovoSourceSelection`, `DeNovoFilterCriteria`, `DeNovoFilter.Passes` |
| 3 | D65 a), ON by default, excludes different-sequence same-precursor anchors before credit; native mass join and PTM/I/L comparison; package-accepted PSMs include decoys and the top-XCorr claim wins; stored choice and old-result retention | `FullXicOptions.PatternLabWinsScanConflicts`, `SeproPsmAdapter.FromResultPackage`, `SpectrumComparisonTable.CreateClaims`, `Ranked`, `BuildClusters`, `ApplyPatternLabConflictRule`, `FullXicCompletionStage.Complete`, `DeNovoReconciler.SequencesEquivalent`, `ComputeXicViewModel`, `QuantManifest`, `ReportMethods.Build` |
| 4 | Identified-equivalent suppression uses run, peptidoform, charge and isotope-aware mass, with I/L folding and separate nonfixed PTMs | `NativeQuantFractions.CrossSideKey`, `IsCrossSideEquivalent`, `Compute`, `PeptidoformIdentity.Canonicalize`, `PrecursorMassEquivalent` |
| 5 | RAW extraction, representative collapse, distinct primary signal bases and no missing-isotope imputation | `FullXicRunStage.Extract`, `QuantRow.FromResults`, `NativeQuantFractions.DedupToPeptides`, `ReferenceEnvelopeEstimator.Apply`, `DeNovoXicExtractor` |
| 6 | PepExplorer-style mapping, default 0.80 identity, I/L handling, recorded score-tier choices, optional decoy identity gate and decoy tie priority | `FamilyEnvelopeQuant.SearchCuration`, `HomologyOptions.DefaultMinIdentity`, `ConsiderILSame`, `HomologyDefaults.ForNewCompute`, `HomologyScienceOptions.ScoreTier`, `HomologyScienceOptions.DecoyGate`, `HomologySearch` |
| 7 | Completed results publish to the project and are read by Results; review is optional and does not compute project quantitation | `MainWindow.PresentQuantifyScreen`, `ProjectStore.WriteFqproj`, `AnalyticsControl`, `DeNovoControl`, `HelpWorkflowFacts.DeNovo` |

The page does not assert that a decoy identity estimate independently validates
identification accuracy. The default identity is a floor; enabled mapping gates
and the recorded policy determine which target matches survive. Optional review
does not apply the D65 Compute rule to an already stored project.
